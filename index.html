核心功能

每一处功能，都源于真实财务工作痛点。告别繁琐手动改格式、反复验算，简单输入就能快速出结果。

实时计算

输入即计算，光标位置之前的结果实时显示。支持自由开关，关闭后按 Enter 手动确认，满足不同习惯。

链式表达式

用 = 串联多步计算，每步以上一步结果为基础自动展开。修改任意数字全链重算，过程可追溯、可复查。

精准复制

双击链式表达式中任意 = 结果 部分即可复制该步结果。告别手动框选，想复制哪步就点哪步。

智能格式识别

直接粘贴带格式文本：1234.56元、1,234.5万元、3500×12+8000 等混合内容，自动过滤文字、单位、千分位符号，一键提取运算内容。

换行续算

开启后按 Enter 换行时自动把上行结果填入新行行首，逐行累计无需反复复制粘贴，配合实时计算连续对账一气呵成。

一键求和 Ctrl+S

扫描全部行，累加每行末尾结果并插入合计行，总和自动复制到剪贴板。财务对账、报表汇总一键搞定。

金额大写转换

一键转中文大写/小写金额，支持千分位格式、负数与小数位控制。自动带入当前计算结果，独立复制按钮，操作便捷。

变量系统 X/Y/Z

内联定义变量，链式依赖自动重算。Ctrl+Shift+X/Y/Z 快速赋值，单击插入变量名，双击赋值，悬停查看值。让分段运算像写草稿一样自然。

计算历史

底部嵌入式历史面板，自动记录计算过程。支持锁定重要记录、逐条删除、左键插入、右键复制结果。

表达式锁定

v3.5 新功能

锁定行受保护，防止误清空删除。浅黄色背景标识，锁的是"防误删"不是"冻结"，仍可正常编辑计算。

常见问题

快速解答使用中的疑问

支持加(+)、减(-)、乘(* 或 ×)、除(/ 或 ÷)、幂(^)、括号()、百分比(%)。其中 * 和 / 会自动替换为 × 和 ÷ 进行视觉美化，不影响计算。百分比如 200×5% 会自动替换为 200×(5/100)。幂运算有限制：小数指数要求底数和指数均非负；整数指数上限 ±1000，底数大于 1 时指数上限 300。

TextCalc 秉持「不求大而全，只做小而专，把小事做到极致」的理念，定位为轻量文本式计算器——加减乘除、百分比、幂运算足以覆盖财务对账、报价核算、数据汇总等日常高频场景。精简的运算符集保证了语法简洁、上手零门槛；遇到三角函数、对数等复杂数学问题，建议配合专业工具使用。

关闭软件后删除与 TextCalc.exe 同目录下的 TextCalc.ini 和 History.json，重启即恢复全部默认值。外观设置对话框中也有「恢复」按钮，可一键将所有外观选项恢复为出厂默认值；也可通过右键菜单逐项调整。

求和只累加行末尾带 = 结果 的行。请确保每行末尾有等号结果（如 = 1,000），无等号结果的行会被跳过。若所有行都无效则静默忽略。提示：Ctrl+Shift+S 同样可触发一键求和。

目前仅支持 X、Y、Z 三个变量，满足绝大多数分段计算场景。如需管理更多中间值，建议在文本中保留相应的计算行作为记录。

点击状态栏 ☷ 标签展开底部历史面板，面板显示最近 8 条（共保留 200 条，可滚轮滚动查看更多）。单击某条记录即可将其表达式插入当前光标位置继续计算，右键可复制该条结果。

默认行为是「关闭到托盘」：窗口隐藏，程序仍在运行，任务栏通知区域显示图标（左键单击恢复，右键可退出）。若需点击 ✕ 直接退出程序，请在右键菜单取消勾选「关闭到托盘」。

默认启用了单实例运行——再次启动会激活已有窗口而非打开新窗口。如需同时运行多个实例，请在右键菜单取消勾选「只允许打开一个窗口」，下次启动生效。

关闭软件 → 删除 TextCalc.ini → 重新启动，窗口将还原到默认位置和透明度。建议通过软件界面调节窗口设置，避免手动编辑配置文件。

v3.4 起采用 Nuitka 编译器将 Python 源码转为 C 并编译为原生 EXE，同时弃用了 UPX 压缩壳（误报高发诱因）。如仍被拦截，请将 TextCalc 添加至杀毒软件白名单。软件完全免费，无任何恶意行为。
