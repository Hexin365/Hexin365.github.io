一、软件简介

TextCalc 专为财务、会计、审计及数据分析人员打造。与普通计算器不同，它以文本行为载体——每一行既是一条计算记录，也是一步可编辑的草稿。输入即计算，过程可追溯、可复查、可复用，整个思考链条完整保留在屏幕上。

实时计算
输入算式即显结果，无需按等号键
链式推导
等号串联多步运算，改任意数字全链重算
混合粘贴
从 Excel、微信复制带文字的内容，自动过滤后计算
金额转换
一键转中文大写 / 小写金额，支持小数位控制
核心理念："所见即所算"——把计算器变成草稿纸。每一行算式都留在屏幕上，结果又能直接参与下一段运算。核对数据时，整条计算路径一目了然，不再担心按错重来。TextCalc 信奉“小而美”的哲学——不贪多，只求精。它只提供加减乘除、百分比、幂运算这些财务人最常用的算力，足以覆盖对账、报价、汇总等日常痛点。因为运算符越少，语法越干净，上手自然零门槛。至于三角函数、对数这类高阶需求，建议您交给更专业的工具，而把TextCalc留给每天都会碰到的那些数字琐事。

二、快速上手

1. 启动

双击 TextCalc.exe 即可运行，无需安装。窗口默认置顶（800×400），可调节透明度浮在其他程序上方使用。

请保持 TextCalc.exe 与同目录下的 LCD.ttf、HELP.html 在一起，解压时勿遗漏。自 v3.6 起 Calc.dat、Hexin.dat 已内嵌进程序，分发文件由 5 个缩减为 3 个，无需再单独拷贝。启动时程序会自动校验所需文件，任一缺失将弹出错误提示并退出。

2. 输入即计算

在文本框中直接输入算式，行尾和状态栏立即显示光标位置之前的结果——这就是实时计算，无需按任何键。

100 + 200
指哪算哪：实时模式下将光标移到表达式任意位置，状态栏显示光标之前的结果，轻松定位中间值。

按 Enter：显示当前行计算结果 / 换行。按 Shift+Enter 强制换行（不计算）。开启「换行续算」且实时计算开启时新行自动继承上行结果。

3. 粘贴混合内容

从 Excel、网页或微信复制一段文字，直接粘贴：

本月收入 12,500.00 元 - 支出 3,280.50 元

软件自动过滤汉字、单位和千分位符，只保留数字和运算符参与计算。

三、计算功能

1. 实时计算

输入时行尾和状态栏动态显示光标位置之前的结果。光标在行内移动时自动重算，方便逐步检查中间值。

模式光标在行中按 Enter光标在行尾按 Enter
实时计算 开 默认跳至行尾（行已被实时处理）换行（换行续算开启则填入上行结果）
实时计算 关计算并显示结果，光标移至行尾已有结果则换行；无结果则先计算（有效表达式再按回车换行，无效表达式自动换行）

2. 链式表达式

用 = 串联多步运算。上一步的计算结果，就是下一步的运算起点：

输入自动补全为
100 + 200 = ×1.13 = -50 =100 + 200 = 300 × 1.13 = 339 - 50 = 289
50000 = ÷1.13 = ×1.06 =50000 = 50,000 ÷ 1.13 = 44,247.79 × 1.06 = 46,902.65
1200 = ×12 = ÷1.13 =1200 = 1,200 × 12 = 14,400 ÷ 1.13 = 12,743.36
规则：首个 = 前为初始表达式；后续 = 后接运算符+数字，以前一步结果为基础计算；若 = 后仅有数字则跳过重算（手动修正中间值）。
实时微调：直接修改表达式中的数字，所有步骤结果立刻更新，无需清空重算整行。
出错灰度标记：若链式中某一步计算出错（如÷0），该步及其后续所有已计算的结果自动变为灰色，状态栏同步显示错误原因。修正错误后灰度自动消失，结果恢复绿色。灰色 = "未确认"——用户能看到中间值辅助定位问题，而非面对一片空白。
亮点功能 · 点哪复制哪

链式表达式有多步结果怎么办？双击任意一个 = 结果 即可复制被点击位置的结果，精准到每一步，无需手动框选。

同时，这一设计还巧妙避免了双击误触选中的困扰：普通文本编辑器双击会选中单词并高亮，在数字密集的界面中极易误触发；TextCalc 将双击绑定为复制，既完成复制又不产生意外选中，一举两得。

3. 换行续算

开启后按 Enter 换行时（需实时计算开启且光标在行尾）自动将上行末尾的计算结果填入新行行首：

100 + 200 = 300           ← 按 Enter
300 × 2 = 600             ← 自动带入 300

4. 一键求和 Ctrl+S

按 Ctrl+S 扫描全部行，累加每行末尾 = 结果 并插入合计行，同时将总和复制到剪贴板：

项目A  100 = 100
项目B  200 + 50 = 250
项目C  1000 × 1.13 = 1,130
              ↓ Ctrl+S
Total 3 Row Sum = 1,480

5. 百分比自动转换

直接在数字后加 %，自动替换为除以 100 的表达式，简化税率、折扣等常见场景：

200 × 5% = 10           ← 等同于 200×(5/100)
8500 + 8500×13% = 9,605   ← 含税价计算

6. 前导零自动补全

输入 .6+.3 时自动补全为 0.6+0.3，无需手工加零。仅对以 . 直接开头的数字生效，1.6 / 0.6 / X.5 不受影响。

.6 + .3        ← 输入
0.6 + 0.3 = 0.9  ← 自动补全后

7. 变量系统

TextCalc 支持三个临时变量 X、Y、Z，用于存储中间计算结果并在后续表达式中引用，让分段运算像写草稿一样自然。

定义变量

有四种方式：

  • 内联定义（推荐）：在任意空行输入 X=表达式（如 X=100+200），按回车后自动求值并生成 100+200=300 → X。写完表达式按回车即完成赋值。
  • 快捷键：在包含表达式的行上按 Ctrl+Shift+X / Y / Z，将当前行结果定义为对应变量。
  • 双击状态栏变量名：双击底部状态栏的 X / Y / Z 标签，将光标所在行的结果快速定义为该变量——手不用离开鼠标即可完成赋值，适合批量处理场景。
  • 右键菜单：右键 →「变量设置」→ 设为变量 X / Y / Z，或右键状态栏变量标签。
覆盖赋值：对已定义的变量再次执行定义操作会覆盖旧值，旧行末尾的 `→ X` 标记也会自动清除。如需清空变量，请使用右键菜单「取消变量 X/Y/Z」或右键状态栏变量标签。

引用变量

在任意表达式中直接写 X、Y、Z，计算时自动替换为对应数值：

X=5000+2000    = 7,000  → X
Y=3000-500     = 2,500  → Y
X+Y            = 9,500
  • 高亮显示：变量名 X/Y/Z 在表达式中以紫色粗体显示，与数字和运算符一眼区分。
  • 悬停查看：鼠标悬停在变量名上 0.5 秒，弹出浮层显示当前值。

状态栏变量标签

状态栏右侧固定显示 X、Y、Z 三个标签：

  • 未定义：浅灰色 X / Y / Z
  • 已定义：紫色加粗，变量值更新时短暂闪烁
  • 光标联动：光标在引用变量的行时，对应标签自动加下划线
  • 单击：已定义时插入变量名到光标位置（200ms 延迟，若 200ms 内再次点击则为双击定义变量）
  • 双击：将光标行结果定义为该变量（覆盖赋值）
  • 右键：取消变量 / 查看当前值 / 跳到定义行

链式依赖

变量支持相互引用。当 X 的值变化时，所有引用 X 的表达式和变量定义自动重算（最多迭代 5 轮处理链式依赖如 X→Y→Z，值稳定后自动停止）：

X=100+50      = 150  → X
Y=X*2         = 300  → Y
Z=Y-100       = 200  → Z
# 修改 X=100+50 为 X=200+100 后，Y 和 Z 自动更新

四、输入与编辑

1. 括号自动配对

输入左括号 ( 时自动补全 )，并将光标定位在括号中间，直接输入内容即可：

(                       ← 输入 (
(100+200)×1.13)    ← 自动补全 )，继续输入

输入右括号 ) 时，如果光标后方已经是 )，则智能跳过（不重复插入），避免打乱表达式结构。

2. 全角符号自动转半角

在中文输入法状态下输入全角符号时，自动转换为对应的半角符号，无需切换到英文输入法：

全角输入自动转为说明
（ ）( )括号，转换后同样走自动配对
＋ －+ -加减号
＊ ／× ÷乘除号，转换后再走 *→×、/→÷
＝ ％ ，= % ,等号、百分号、千分位逗号

粘贴混合内容时同样自动转换全角符号。

3. 表达式自动空格

开启后，输入表达式时自动在运算符两侧添加空格，提升可读性；关闭后表达式保持紧凑无空格格式。

100+200×3          ← 输入
100 + 200 × 3 = 700  ← 自动加空格
格式规则：运算符 + × ÷ ^ % = 两侧自动加空格；负号不加空格（行首、括号后、运算符后的 - 视为负号，如 100 + -50）；变量后缀 →X 两侧不加空格。切换开关时，窗口内所有表达式同步重新格式化。

默认关闭，通过右键菜单「表达式自动空格」切换，状态保存至配置文件。

4. 表达式锁定

在包含重要表达式的行上右键 → 锁定此行（或按 Ctrl+L 快捷键），该行即以浅黄色背景标识，受保护防止误删：

  • 快捷键：Ctrl+L 快速切换当前行锁定/解锁状态，双手无需离开键盘。
  • 防删不禁改：锁定行进行清空操作后不会被删除，但仍可正常编辑数字、重新计算——锁的是"防误删"，不是"冻结"。
  • 清空保护：Ctrl+D 清空时，锁定行按原顺序紧凑排列保留，非锁定行全部删除。
  • 位置自动跟踪：在其他行插入或删除时，锁定标记自动跟随，无需手动维护。
  • 自动保存：锁定状态保存至配置文件，重启后自动恢复。
  • 解锁：在锁定行上右键 → 解锁此行（或再次按 Ctrl+L），即可恢复正常状态。

五、数字与格式

小数位与舍入方式

双击状态栏「小数位」标签弹出设置对话框，可配置以下三项：

设置含义
10 默认保留 10 位小数（日常使用推荐）
-1不限制，显示最多 28 位小数（高精度需求）
0只保留整数部分
1 ~ 15保留指定位数小数
舍入方式说明示例
四舍五入 默认通用场景3.1450 → 3.15
向下取整保守估算3.1499 → 3.14
向上取整采购备货3.1401 → 3.15

不足补零

设置小数位后，决定位数不足时的显示方式。在上方「小数位设置」对话框中勾选即可：

状态结果 3.1（设置 2 位）结果 5（设置 2 位）
开启 默认关3.105.00
关闭3.15
高精度计算：内部使用 Decimal 28 位有效数字，消除浮点误差。默认保留 10 位小数，设为 -1 可显示完整 28 位精度。

金额转换

单击状态栏 ¥ 按钮，弹出转换窗口，自动带入当前结果，也可手动输入。各结果旁有独立复制按钮：

转换类型示例（1,234,567.89）
中文汉字小写一百二十三万四千五百六十七点八九
中文大写金额壹佰贰拾叁万肆仟伍佰陆拾柒元捌角玖分
支持负数：输入负数金额（如 -1,234.56）可自动转换为"负壹仟贰佰叁拾肆元伍角陆分"。

状态栏

📐 右区布局：X Y Z | ¥ ☷ | 小数 分节 复制 实时 续算 置顶 ⚙

第二组：快捷功能入口
第三组：开关设置与自定义菜单

  • 右区：分节、复制、实时、续算、置顶标签双击切换开关；¥ / ⚙ / ☷ / X / Y / Z 标签单击触发对应操作。绿色 ● = 开，灰色 ○ = 关。

  • 悬停高亮：所有状态栏标签鼠标悬停时颜色自动变化，浅色标签加深、深色标签变亮，提供即时视觉反馈

计算历史面板

TextCalc 自动记录每次完成计算时的表达式和结果，点击状态栏 ☷ 标签即可展开底部历史面板，方便回溯和复用之前的计算。

面板操作

操作效果
单击历史行将表达式插入到当前光标位置
右键历史行复制该条结果到剪贴板
滚轮滚动滚动历史列表（超过 8 条时）
清空按钮清除非锁定条目（全部锁定时不执行）
再次点击 ☷关闭面板

条目管理

每条记录右侧有两个操作图标：

  • 锁定 ○/●：点击切换锁定状态。锁定 ●（红色）的记录不受"清空"操作影响，适合保留重要计算结果。
  • 删除 ✕：移除单条记录。锁定记录的删除图标显示为灰色（不可用），保持列表整齐。

记录规则

  • 自动记录：非实时模式 Enter 计算、实时模式 Enter 换行、变量赋值（X=表达式 / → X 后缀）均自动记录
  • 不记录：实时模式下逐键输入时的中间结果
  • 智能去重：与上一条完全相同的记录自动跳过
  • 容量上限：最多保留 200 条，超出后自动移除最早的记录
  • 自动保存：记录保存至 History.json，重启软件后依然可查
提示：☷ 标签展开面板时变为绿色 ●，折叠时恢复灰色 ○，一眼可知面板是否处于激活状态。

字体

默认使用内置 LCD 数码管字体（LCD.ttf）。右键「外观设置 → 字体与配色…」可勾选「使用默认字体」或选择其他字体，字号 8～72（默认 20），底部有实时预览区。对话框底部「恢复」按钮可一键将所有外观选项（字体、字号、数字/符号/结果颜色）恢复为出厂默认值，预览后点「确定」生效。

窗口透明度

右键「外观设置 → 窗口透明度…」弹出滑块对话框，范围 20%～100%，支持实时预览。也可用 Ctrl+Shift+滚轮快速调节（每次 5%），编辑区中央浮层实时显示百分比，停止操作后自动消失。

🖥️ 浮动参照：Ctrl+Shift+滚轮调低透明度，让 TextCalc 半透明叠在 Excel 上方，边看数据边计算。

当前行高亮

光标所在行自动以浅蓝色（#e8f0fe）背景高亮显示。在多行计算中，这一视觉提示让你始终清楚正在编辑的是哪一行，避免将输入写到错误位置。光标移动时自动跟随，无需手动操作。

常见问题

支持哪些运算符？
支持加(+)、减(-)、乘(* 或 ×)、除(/ 或 ÷)、幂(^)、括号()、百分比(%)。其中 * 和 / 会自动替换为 × 和 ÷ 进行视觉美化，不影响计算。百分比如 200×5% 会自动替换为 200×(5/100)。幂运算有限制：小数指数要求底数和指数均非负；整数指数上限 ±1000，底数大于 1 时指数上限 300。
为什么只支持基本的四则运算及幂运算？
TextCalc 秉持「不求大而全，只做小而专，把小事做到极致」的理念，定位为轻量文本式计算器——加减乘除、百分比、幂运算足以覆盖财务对账、报价核算、数据汇总等日常高频场景。精简的运算符集保证了语法简洁、上手零门槛；遇到三角函数、对数等复杂数学问题，建议配合专业工具使用。
如何重置为默认设置？
关闭软件后删除与 TextCalc.exe 同目录下的 TextCalc.ini 和 History.json，重启即恢复全部默认值。外观设置对话框中也有「恢复」按钮，可一键将所有外观选项恢复为出厂默认值；也可通过右键菜单逐项调整。
一键求和 (Ctrl+S) 没反应？
求和只累加行末尾带 = 结果 的行。请确保每行末尾有等号结果（如 = 1,000），无等号结果的行会被跳过。若所有行都无效则静默忽略。
提示：Ctrl+Shift+S 同样可触发一键求和。
能增加 X、Y、Z 以外的变量吗？
目前仅支持 X、Y、Z 三个变量，满足绝大多数分段计算场景。如需管理更多中间值，建议在文本中保留相应的计算行作为记录。
如何查看和复用之前的计算？
点击状态栏 ☷ 标签展开底部历史面板，面板显示最近 8 条（共保留 200 条，可滚轮滚动查看更多）。单击某条记录即可将其表达式插入当前光标位置继续计算，右键可复制该条结果。
关闭窗口为什么没有退出程序？
默认行为是「关闭到托盘」：窗口隐藏，程序仍在运行，任务栏通知区域显示图标（左键单击恢复，右键可退出）。若需点击 ✕ 直接退出程序，请在右键菜单取消勾选「关闭到托盘」。
双击程序打不开第二个窗口？
默认启用了单实例运行——再次启动会激活已有窗口而非打开新窗口。如需同时运行多个实例，请在右键菜单取消勾选「只允许打开一个窗口」，下次启动生效。
窗口消失了或移出屏幕怎么办？
关闭软件 → 删除 TextCalc.ini → 重新启动，窗口将还原到默认位置和透明度。建议通过软件界面调节窗口设置，避免手动编辑配置文件。
杀毒软件报毒怎么办？
v3.4 起采用 Nuitka 编译器将 Python 源码转为 C 并编译为原生 EXE，同时弃用了 UPX 压缩壳（误报高发诱因）。如仍被拦截，请将 TextCalc 添加至杀毒软件白名单。软件完全免费，无任何恶意行为。
